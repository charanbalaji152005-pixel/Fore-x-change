# Fore-x-change 💱

A beginner-friendly 5-page Foreign Exchange (Forex) & NRI Remittance web application built with **React**, **React Router**, and **modular CSS**.

---

## 🌟 Live Demo
- **URL**: [https://charanbalaji152005-pixel.github.io/Fore-x-change/](https://charanbalaji152005-pixel.github.io/Fore-x-change/)

---

## 📄 Pages & Themes

1. **Home (`/`)**
   - **Theme**: Dark Blue (`#0d1b2a`) with white text and cyan highlights.
   - **Features**: Live-style ticker banner with sample rates (`USD/INR`, `EUR/USD`, `GBP/INR`), hero section with "Get Started" CTA, and ambient background floating currency icons (`FaRupeeSign`, `FaDollarSign`, etc.).

2. **Currency Converter (`/converter`)**
   - **Theme**: Green (`#2e7d32`) accents on a clean light background.
   - **Features**: Dual currency selectors (`USD`, `EUR`, `INR`, `GBP`, `JPY`), amount input, swap button, **popular NRI Inward Transfer presets** (`USD → INR`, `GBP → INR`, `EUR → INR`, `JPY → INR`), and converted breakdown.

3. **Exchange Rates (`/rates`)**
   - **Theme**: Purple (`#6a1b9a`) table header with light gray alternating rows and smooth hover effects.
   - **Features**: Real-time style market rate snapshot, bid/ask prices, 24h change indicators, and interactive search filter.

4. **About (`/about`)**
   - **Theme**: Warm Orange (`#e65100`) highlights.
   - **Features**: Plain-English explanation of Forex and currency exchange, daily global turnover statistics, and a 3-card feature grid.

5. **Contact (`/contact`)**
   - **Theme**: Teal (`#00838f`) with soft background.
   - **Features**: Controlled contact form (Name, Email, Inquiry Topic, Message), submit alert confirmation, and helpline cards.

- `npm run build` - Build production bundle to `/dist`
